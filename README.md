# AI Resume Formatter

A web app that formats and polishes resumes using AI. Built with React, Vite, and TypeScript.

## Features

- Paste any resume text and format it instantly
- Choose from three styles: **Professional**, **Creative**, or **Technical**
- Dark-themed, responsive editor UI
- Copy the formatted result to clipboard in one click

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

The app is automatically deployed to GitHub Pages on every push to `main`.  
Live URL: `https://<your-username>.github.io/ai-resume-formatter/`
